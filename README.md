## Giới thiệu ứng dụng
Ứng dụng quản lý thông tin đơn giản gồm:

- **Frontend:** React.js
- **Database:** MySQL

## Các tính năng & API
- `GET /about`: Hiển thị thông tin sinh viên.
- `GET /health`: Kiểm tra trạng thái hệ thống.
- Triển khai bằng Docker & Docker Compose.

## Cách chạy ứng dụng
1. Đảm bảo đã cài đặt Docker.
2. Chạy lệnh: `docker-compose up -d --build`
